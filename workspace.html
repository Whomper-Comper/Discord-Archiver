Export formats

Compact JSON saves names, IDs, text, and reply relationships with short keys and one shared schema legend for AI analysis. It omits repeated source fields, empty metadata, and reply quotations when the target ID is available. Full-detail formats are optional.

Gzip reduces storage further and must be decompressed before AI analysis. You can import gzip files here to decode them. Compression and output size depend on the content.

HTML quality and file size

Exact embedded records repeat message data and increase HTML size. Compact HTML keeps text and identity attributes for parsing; omitted media/details require a full-detail export.
